Knowledge Base & Propositional Logic

The Knowledge Base (KB) uses Propositional Logic to infer absolute truths about the Wumpus World.

Forward Chaining Rules

  • NOT Breeze(x,y) ⟹ ∀ adj, NOT Pit(adj)
  • NOT Stench(x,y) ⟹ ∀ adj, NOT Wumpus(adj)
  • Safe(x,y) ⟺ (NOT Pit(x,y) AND NOT Wumpus(x,y))

Example Trace: If the agent visits (0,0) and detects no breeze, it immediately concludes that adjacent cells (0,1) and (1,0) do not contain pits.

Search (Pathfinding)

Once a target cell is decided by the logic engines, the agent must navigate there safely through known territory.

A* Search (Hybrid Agent)

Uses the Manhattan Distance heuristic: h(n) = |x1 - x2| + |y1 - y2| to find the shortest safe path to the target. Time complexity: O(b^d).

Breadth-First Search (Baseline Agent)

The BFS Baseline agent does not use logic. It blindly expands its frontier uniformly, checking adjacent cells regardless of safety. Time complexity: O(V+E).
